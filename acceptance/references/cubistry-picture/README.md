# Native Picture3 reference

The sources are unchanged from Cubistry revision `efafcc1d97687eccea0cde87a230f447ce1b6c66` and hashed in `source-manifest.json`. The original code is AGPL-3.0-or-later (see LICENSE). `presets.ts` identifies its artwork as CC BY-SA 4.0, attribution Werner Stein, Cubistry; its source notice is retained. The coast preset creates six different SVGs, internally rasterized to PNG by the original editor, then decoded, cropped and divided into 54 tiles by the original code. User SVG uploads are rejected by the original decoder. No additional file-format coverage is asserted.

This local comparison is not visual acceptance or publication. The shared and source scenes use the same native editor tile canvases; source and Core state are compared by all sticker positions, normals and up vectors. Browser/device, lighting, crop and interaction parity remain UNKNOWN until measured.
